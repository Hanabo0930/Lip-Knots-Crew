# 実業務シフト表との連携要件（2026-09-06）

## 原本の扱い

ユーザー共有のGoogle Sheets「シフト表」を読取専用で調査。元URLは外側CODEX_START_HERE.mdに記録し、個人名・連絡先・案件明細はリポジトリや証跡へ複製しない。セル・数式・色・タブ・共有設定の変更禁止。実表の再取込commitや書戻しも未承認。開発と検証は合成データで進める。

## ユーザー確定の業務仕様

- 年月名のタブが稼働するシフト。対象は表示中タブ。非表示は取込対象にしない。
- 将来は依頼案件をすべて行として登録する運用を希望。
- B列「スタッフ名」が空欄なら応募可能な案件として表示する。F列は募集判定に使わない（ユーザー回答で確定）。日付・店舗・実施時間など必要項目が不足した空行は公開しない。
- キャンセル行をスプレッドシートでグレーアウトしたらアプリで非表示にしたい。
- ユーザーの追加案: 専用チェックボックスをONにしてキャンセルとし、条件付き書式で行をグレーアウトする。判定元は背景色ではなくチェック値にする。既存GAS・仕組みへの影響を避ける。原本変更の許可とは扱わない。

## 読取で確認した構成

2026.9、2026.10、2026.11のヘッダーは同じ55列。A実施日、Bスタッフ名、Fスタッフ名、G体温、H入店時間、Jクライアント、K店舗、Lメーカー、Mメニュー、N入店時間、O実施時間、P備考、R資料発送日。Sは請求単価、ABは給与、AJは基本給。明細は出力していない。

表示中年月タブは2026.8〜2026.11。非表示には過去月だけでなく2026.12以降の将来月もあるため、年月が将来だからといって非表示タブを取り込まない。2026.9のA2:R80は書式のみ参照。複数の通常色と暗色の区切りがあり、グレーの意味は推定していない。

## 実装照合と不足

- sheet-reader.tsは既に表示中タブと年月パターンで選別する。
- shift-parser.tsは割当名が空欄で必要項目が揃えばopenにし、キャンセル/募集停止を優先する。既存設定例のstaffNameはBで合う。
- 現行readShiftSheetはvalues.getのみで背景色を読まない。ただし専用キャンセル列のTRUE/FALSEは既存parserで判定可能。チェックボックス方式なら背景色読取を追加せずに済む。実表の列設定・条件付き書式・同期の接続は未実施。
- ASは既に報告書チェック。専用キャンセル用途へ転用しない。BCはヘッダーが空だが、列全体の未使用・GASの非参照は未確認で、実装先と断定しない。
- 設定例ではPをsubcontractorNameとしているが、実表ヘッダーは備考。basePayColumnsは請求側S:Zを参照する設定例で、実表のスタッフ給与との対応も監査が必要。実稼働設定を確認せず、設定例が現行の正しい給与マッピングと断定しない。
- 既に取り込まれた案件をタブ非表示後にどう扱うかは、新規取込除外とは別。履歴の保存と応募停止の要件を分けて設計する。
- 背景色を検知した後、既存応募・確定者・下書き・履歴を消さずに非表示/応募不可へ遷移する必要がある。物理削除ではなく状態更新を基本案とする。

## 次の実装・受入

1. 合成セルで「B空欄/F入力」「B入力/F空欄」「両方空欄」「空白のみ」「必須不足」「キャンセル優先」を試験。
2. 専用キャンセルチェック列を確定し、TRUEをキャンセル、FALSEを通常判定へ戻す仕様を検証。グレーアウトは条件付き書式で行う案。色だけを変更してもキャンセルにはしない。解除時の既存応募・割当・履歴の扱いは別途受入。
3. 日付/スタッフ/料金/備考等の実列対応と、既存保存先・会社分離を読取で監査。
4. 実原本と実データへ反映する段階は別途明示許可が必要。Functions反映もHosting包括承認に含めない。
## 列追加の影響調査と実施前条件

途中への列挿入は避け、既存列番号を動かさない案とする。ただし末尾でもgetLastColumn/getDataRange、固定配列長、CSV/PDF出力、月次テンプレート、IMPORTRANGE/QUERY、条件付き書式・保護範囲へ影響し得る。未使用列の再利用も同じ確認が必要。Apps Script本文、トリガー、連携元/先を読取で監査してから設置案を確定する。ローカルGAS_FILE_INVENTORYは未記入で、実GAS本文は未確認。ユーザーへプロジェクトURL/保存場所を依頼中。

合成試験でB空欄/F入力、B入力/F空欄、空白のみ、専用チェックTRUE/FALSE、AS報告書チェックのONをキャンセルと混同しないこと、必須不足とキャンセル優先を検証する。BCはテスト専用の仮列であり、実表の採用列や設定変更ではない。
